A Muse AI invite code gives you and the friend who shared it a bonus of 1 billion tokens each, if you enter it within 48 hours of signing up. You do not need a code to use Muse. A code is only a bonus.

## How invite codes work

According to Meta's announcement, as reported by reviewers:

- You enter a friend's code in Muse settings within 48 hours of creating your account.
- You and the friend who shared the code each receive 1 billion tokens.
- After the 48 hour window, the sign-up bonus no longer applies.

For comparison, the free weekly limit is reported at about 100 million tokens, so 1 billion tokens is a large boost. Our guide to the [Muse free limit](/blog/muse-ai-free-limit-how-many-tokens) shows what that means in practice.

## How many times can a code be used?

Reports differ. Meta's own post, as quoted by reviewers, said a person can invite up to 20 friends, which is roughly 20 billion bonus tokens. Screens shared on X suggested a code could be used 30 times. Meta has not published one definitive rule, so assume a code can fill up and stop working.

## Why codes you find online often fail

Many websites publish referral codes. Because each code has a limited number of uses, popular ones fill up quickly and the page may still show them. If a code is rejected, it is usually full or you have passed the 48 hour window. Try a different code, or ask a friend who already uses Muse.

## How to stay safe

1. **Never share your Meta or Muse password.** An invite code is the only thing anyone legitimately needs from you.
2. **Do not pay a stranger for a free bonus code.** Codes are free to use, so a paid code from an unknown person is a red flag.
3. **Use only the official app or muse.ai** to enter a code.
4. **Be careful with sites that ask you to log in** to claim a bonus. Muse bonus tokens are entered inside your account, not on a third-party site.

## Your own code and token top-ups

Your Muse account has its own invite code that you can share. Some sellers, including DigiVerse, use that code as the destination for a token top-up. This means the tokens are added to the account that owns the code, and the seller does not need your password. Always check the code before you pay, because the tokens go to the account behind whatever code you enter. You can see how this works on our [Muse AI tokens page](/muse-ai-tokens). If Meta's own purchase option works for you, it is the official route.

## Frequently asked questions

### Do I need an invite code to use Muse AI?

No. Signing up does not require a code. A code is only an optional bonus.

### How many tokens does an invite code give?

1 billion tokens to you and 1 billion to the friend who shared it, according to Meta's announcement as reported by reviewers.

### How long do I have to enter a code?

48 hours after you sign up.

### Why does my Muse invite code say it is invalid?

Common reasons are that the code has reached its use limit, the 48 hour window has passed, or the code was typed incorrectly.

### Can invite codes unlock Muse in my country?

No. Access depends on your Meta account and region. See [which countries can use Muse AI](/blog/is-muse-ai-available-in-your-country).
